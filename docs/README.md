# Little Joys — build pack

A small, direct-touch toybox for enjoyable independent exploration and optional same-screen family play. The initial product contains **Squishy Friend, Bubble Pond, and Roll & Nest**.

This folder preserves the researched specification and implementation handoff. The runnable application is now at the repository root: see [setup instructions](../README.md) and [delivery evidence](DELIVERY.md) for actual implementation, test, and deployment status. “Little Joys” is a working title, not a checked product name.

## Start here

Give the implementation agent this folder and `CODEX-PROMPT.md`. `SPEC.md` is the normative product and engineering contract. `TASKS-AND-ACCEPTANCE.md` provides the execution order and release tests. `ASSETS.md` contains the art brief and generation prompts. `RESEARCH.md` explains the evidence and its limits. `SOURCES.md` contains the source register. `PLAYTEST.md` is the family's observation template.

The first deployable vertical slice is **Squishy Friend plus the reliable app shell**. The complete first-version scope is all three toys and the shared requirements. A one-toy preview must not be described as the complete MVP.

Build a new, separate project. The owner has authorised selective reuse of assets from `MachineKomi/maze-so-puzzle`; do not modify that repository or copy its entire game. Keep the application's public identity neutral. Do not publish private family transcripts, names, diagnoses, photographs, or playtest notes.

Research checked: 13 September 2026. Performance numbers are proposed engineering targets, not measurements. The design is evidence-informed; the new product has not been clinically evaluated.
